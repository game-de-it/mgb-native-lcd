# Changelog

## v0.1.0 — 2026-11-12

- Added the accepted two-pass MGB LCD preset with fixed surface grain, motion-dependent grain contrast, four-shade response, color gains, and bezel shadow to a self-contained `shader-only/` directory.
- Added bilingual installation and model documentation. RetroArch Integer Scale ON is documented as a required display setting.
- Preserved development experiments and device-specific deployment notes for review before a public release.
- Prepared separate Standard and plumOS-pixel2 shader packages; Standard is the default for other compatible devices, while Pixel2 carries its tested final-pass rotation and GB launch settings example.
- Added the physical MGB/Pocket Block comparison and three RetroArch captures to the bilingual READMEs, and adopted the MIT License for the shader and project documentation.
- Documented all 16 RetroArch shader parameters in English and Japanese and included both guides in each shader archive.
